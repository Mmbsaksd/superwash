- **Category A:** Original Intended Application Data (Must Preserve)
- **Category B:** Required Default / Reference Data (Must Preserve)
- **Category C:** Confirmed Development or Test Data (Propose for Removal)
- **Category D:** Confirmed Duplicate or Obsolete Data (Propose for Removal)
- **Category E:** Unknown-Origin Data (Requires Decision)

## 3. Data Flow & Automatic Generation Audit

### When Application Starts / Page Loads
1. In Live Mode (`VITE_DEMO_MODE=false`):
   - Reads `business_settings`, `pickup_slots`, `service_areas`, and `services` directly from Supabase.
   - Does **NOT** insert or create any records automatically.
   - Reads authenticated user session from Supabase Auth (`supabase.auth.getSession()`).
2. In Demo Mode (`VITE_DEMO_MODE=true`):
   - Reads settings from `localStorage` under `superwash_settings`. If missing, caches `DEFAULT_SETTINGS`.
   - Reads orders from `localStorage` under `superwash_orders`. If missing, seeds `INITIAL_SAMPLE_ORDERS`.
   - Reads active persona from `superwash_auth_profile`.

### When Booking Wizard Runs (`BOOK-CONFIRM-01`)
- In Live Mode: Calls idempotent RPC `create_order_atomic` or inserts into `public.orders`. Generates next sequential order number via database sequence.
- In Demo Mode: Appends order to `superwash_orders` array in `localStorage`. Generates `SW-1003` via client-side sequence counter.
